⬇️ TikTok Downloader — KONZZY PRIME

Tempel satu link TikTok publik. Pilih format yang kamu perlukan. Untuk MP4/MP3, KONZZY PRIME akan menyalin link lalu membuka TikTokio agar kamu bisa memprosesnya di sana. Jangan unduh atau gunakan ulang konten tanpa izin kreator.

Tempel link TikTok, lalu pilih MP4, MP3, atau foto.
Catatan: TikTokio memproses video publik untuk MP4/MP3. Dukungan slideshow foto dapat berbeda; bila tidak tersedia, gunakan menu Bagikan → Simpan foto di TikTok jika kreator mengizinkan.

✦ Preset Alight Motion (AM)

Ambil file preset dari tautan yang dibagikan kreator, atau unggah file XML/proyek yang sudah kamu dapatkan. KONZZY PRIME tidak bisa membangun preset asli hanya dari video MP4.

📦 Ambil preset & XML dari link VT TikTok

Tempel link VT TikTok. KONZZY PRIME akan membuka sumber video dan membantu mencari link preset/XML yang dibagikan kreator. Jika kreator menyediakan link Alight Motion, tempel link itu untuk impor.

Tempel link VT TikTok untuk mulai mencari sumber preset yang dibagikan kreator.
Cara menggunakan link
  1. Salin link preset/proyek yang dibagikan kreator.
  2. Tempel ke kolom link, lalu tekan Ambil preset & XML.
  3. Jika link Alight Motion, buka di Android dan tekan Import.
  4. Jika link file XML/proyek langsung, file akan dicoba diunduh dari sumbernya.
Link TikTok saja tidak berisi XML atau data proyek. File XML hanya bisa diunduh jika kreator memang menyediakan URL file XML.
